# CalculateInline
 
**Stop pasting numbers into Excel just to add them up.**

Select a list of numbers anywhere, such as a report, a web page or an email, and press Alt+C. You get the sum, average, median and count at once. If the numbers are 0–10 survey scores, you also get the Net Promoter Score. Press one key to copy the value you need and you're back where you were. There's no workbook to open, no messy paste to clean up, and nothing to close without saving.

It also does the maths where you're typing. Select 1250*12, press Alt+C, and it becomes 15000.

It works in any Windows app where you can select text, and handles both European (1.234,56) and American (1,234.56) number formats.


## FEATURES:
## Nothing selected:
- Hotkey opens a simple calculator dialog

## If mathematical expression is selected:
- Replaces selected mathematical expression with calculation results
- To undo press Ctrl+Z

## If numbers are selected:
- A results window shows:
  - sum
  - count
  - average (mean)
  - and median
  - NPS (Net Promter Score, only when every value is a 0-10)
    
## Copy any single value, or all of them, with one button - nothing is
  copied until you press one of those buttons
- Press the following and close the window in one keystroke:
  - S = Sum
  - A = Average
  - M = Median
  - C = Count
  - N = NPS
  - 4 = all values 

## Supports for numbers with thousand separators
- All values are displayed with two decimal places

## Settings:
- Configurable hotkey via tray menu
- Toggle between European/American number format
